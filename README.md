# 火線暴走：鋼鐵縱隊

一款直式全螢幕的街機式縱向捲軸射擊遊戲，六個戰區、三隻輪替 Boss、原創程序化音樂與 AI 生成配樂。

## 怎麼玩

**打開瀏覽器就能玩，不需要安裝任何東西：**

前往 [線上遊玩頁面](../../deployments/github-pages) 直接開始。整個遊戲是一個單一 HTML 檔案，所有程式、美術與音樂都內嵌其中。

首次載入需要下載約 23MB（配樂佔絕大部分），期間會顯示載入提示；載入完成後即可離線遊玩，重新整理也會走瀏覽器快取。

> **排行榜需要網路。** 遊戲本體完全可以離線玩，但上傳成績與查看排行榜會連線到 Supabase。沒有網路時只是看不到榜單，不影響任何單機進度。

也可以下載 `docs/index.html` 到本機，雙擊或拖進瀏覽器視窗直接開啟。

支援桌面瀏覽器與手機瀏覽器（建議使用全螢幕模式遊玩）。

## 音樂授權說明

本作配樂由 AI 音樂生成工具製作，於各檔案內嵌有 C2PA 內容溯源標記。若你要基於本專案二次散布或商用，請自行確認所用生成工具當下的服務條款。

## 開發者：原始碼與建置說明

這份目錄是遊戲的可維護原始碼；正式交付仍會建置成一個可直接開啟的單檔 HTML。這樣開發時能分開管理規則、戰鬥、畫面與存檔，玩家端則不需要安裝伺服器或額外檔案。

## 開發與建置

需要 Node.js **20.19** 以上，或 22.12 以上（Vite 7 的最低需求；Node 20.0～20.18 會安裝失敗）。

```bash
npm install
npm run dev
npm test
npm run build
```

`npm run build` 會產生 `dist/index.html`；CSS、JavaScript、SVG 美術與本機匯入的音訊都會內嵌在這一個檔案中。

### 部署

線上版由 GitHub Pages host `docs/index.html`，所以建置成品要進版控：

```bash
npm test                       # 先確認測試全過
npm run build
cp dist/index.html docs/index.html
git commit && git push         # 等 1-2 分鐘部署，強制重新整理測試
```

> ⚠️ 根目錄的 `index.html` 與 `docs/index.html` **不是同一個東西**。前者是 2.5KB 的 Vite 進入點（空殼＋載入提示＋一行 script 標籤），後者是 23MB 的建置成品。不要互相覆蓋——把成品放到根目錄會讓 Vite 拿它當進入點，之後改原始碼 build 出來都不會有任何變化。

> 一旦 `src/audio-assets.js` 接上了真實音訊檔案（`src/assets/audio/`），輸出的單檔 HTML 會膨脹到數十 MB（目前約 23MB），超過原本給純程式合成音樂設計的 160KB 精簡版門檻。`scripts/pack-portable.mjs` 在超過門檻時會直接跳過、不會讓整個 build 失敗，`dist/index.html` 本身仍是完整可離線遊玩的單一檔案。

### 載入提示

根目錄 `index.html` 的 `#boot-loading` 區塊會在下載期間顯示轉圈動畫與說明文字，載入完成後由應用掛載時自動取代（`mount()` 會覆寫 `#root` 的內容），不需要另外清除。

⚠️ **這個區塊必須放在 `<script type="module">` 之前，不能調換順序。**

單檔建置會把整個遊戲連同音訊內嵌成一個巨大的 inline script。瀏覽器是由上往下解析的：提示若排在 script 之後，要等 23MB 全部下載完才會被解析到，那時遊戲本身也已經載好了，提示等於形同虛設——玩家看到的是長達數十秒的白畫面。放在前面則約下載到 62KB 就能顯示。

這個約束**不會被測試抓到**，順序錯了遊戲照樣能跑，只是回到白畫面。改動 `index.html` 結構時請特別留意。

## 主要模組

- `src/config.js`：指揮官、武器、研究、支援、敵軍與經濟數值。
- `src/game/state.js`：單局狀態、傷害公式、裝甲上限、檢查點序列化。
- `src/game/combat.js`：直射戰鬥、Boss、空投、戰術門、支援與撤退規則。
- `src/game/render.js`：Canvas 戰場繪製。
- `src/fullscreen-layout.js`：直式全螢幕延伸戰線、機動觸控區與各種指標裝置的位移換算。
- `src/ui.js`：選單、HUD、研究、三系列成就與警告畫面。
- `src/music-score.js`：六戰區與三種Boss的十六小節原創和聲、旋律、低音、琶音、脈衝與鼓組樂譜。
- `src/audio.js`：音訊生命週期、樂譜排程、動態混音、合成音色與外部音軌播放。
- `src/audio-assets.js`：外部音樂分軌與音效插槽；素材放在 `src/assets/audio/`。
- `src/storage.js`：V6 存檔、舊版遷移、每日任務與永久進度。
- `src/leaderboard.js`：Supabase 排行榜的網路層——三個分類榜的查詢、成績上傳、個人紀錄判定與暱稱清洗。
- `supabase-schema.sql`：排行榜資料表、RLS 政策與三個分類 view 的結構定義（只在後端變更時需要執行）。
- `tests/`：核心規則與進入點結構的自動測試（164 項）。

## 本版關鍵規則

- 初始機凌風獨立置頂；可招募戰機依Boss威脅與價格由低至高排列。
- 武器自動開火但只向正前方直射，不會追蹤敵人。
- 敵軍進入畫面後才會受到玩家火力判定，離開畫面的子彈不能在場外攔截新生成單位。
- 自然火力狂熱需要30次連續擊破，效果期間不累積下一輪，結束後另有10秒冷卻；戰場支援與指揮官技能維持原效果。
- 戰術武器最高 `LV.9`，滿級顯示 `LV.MAX`；永久火力研究仍獨立計算。
- 基礎裝甲容量為 14，裝甲研究每級同時增加 1 點開局裝甲與 1 點容量，最終上限為 23。
- Boss 前士兵空投為 `+1`，Boss 戰為 `+2`；Boss 第二、第三階段各固定提供一次 `+2`。
- 三種戰場支援每個 Boss 循環各限用一次；醫療／火力／充能的基礎費用為 ◆80／60／40，並隨已擊破 Boss 數逐輪提高。使用狀態跨檢查點與強制撤退保留，擊破下一隻 Boss 後重置。
- Boss 擊破後有醒目的 10 秒安全整備窗口；其他時間只能暫停，強制撤退會回到上一個 Boss 檢查點。
- 開始頁只保留一條進行中戰線：真正首次遊玩顯示「菜鳥出擊」，曾出擊但無檢查點顯示「開始新一輪」，並明示不會清除永久養成；有檢查點時提供「再續光榮」、研究整備，以及需二次確認的放棄戰線重新出擊。放棄只刪本輪檢查點，永久進度不受影響。
- 開始頁底部的「資料管理」可查看目前永久進度；真正砍掉重練必須再進入獨立警告頁並持續按住3秒。完成後會清除現行存檔、Boss檢查點與所有舊版遷移資料，重新載入為「菜鳥出擊」，且無法復原。
- 開始頁與暫停畫面提供全螢幕切換並保存玩家偏好；首頁的全螢幕選項獨立置中。瀏覽器或系統離開全螢幕後，下一次出擊、續關或戰場觸控會再次嘗試恢復。
- 直式全螢幕會把長螢幕多出的高度真正投入戰鬥：上半部成為敵軍提早現身的接近戰線，下半部成為不受支援／技能鈕遮擋的獨立機動觸控區。接近中的一般敵軍在越過接敵線前不可受傷，因此不會多送玩家免費火力時間；接敵線只保留細虛線，不再疊加右側文字框。
- 手機觸控與觸控筆在全螢幕、網頁版及一般短版全部採相對拖曳，按下時不會瞬移；拖曳離開區域後仍持續捕捉同一根手指。全螢幕下方機動區另外允許另一根手指同時操作支援或指揮官技能；滑鼠保留直接定位，鍵盤維持方向鍵／A、D。
- 首頁士兵隊形整體上移，並改成清楚的 1－2－4 楔形展示，不再由最下方單獨一名士兵頂住上一排中央；直式全螢幕首頁會吃滿完整高度。永久進度提示整合進出擊按鈕，「戰績成就」與提示文字都不會再被隊員遮住。
- Boss 後只能研究並維持同一位指揮官；結束整輪後才解除機體鎖定。
- 每次Boss之間仍需完整通過三段戰區，但戰區池擴為六種：前三區建立基礎，第二輪進入熔爐、雪原與天穹，之後以存檔種子重排三區且避免緊鄰重複。
- 六個戰區各有專屬場地機制：港區灘頭炮擊（兩側固定、中央安全）、峽谷裝甲彈幕（三條隨機窄帶）、都城空優轟炸（鎖定當下位置的大圓）、熔爐輪替熱區、雪原安全通道、天穹跟隨指揮官中心的空襲鎖定；預警與命中判定都以指揮官位置為準，不會因36人隊形過大而無法閃避。
- 場地機制對新帳號採漸進爬坡：第一輪完全不出現，第二輪三個戰區中隨機一個開啟，第三輪隨機兩個，第四輪起全開。帳號只要通關過一次（擊破第三隻Boss摩洛克）就永久標記為已畢業，之後任何新局第一輪就全開，不必重爬；舊存檔依「機甲屠夫」成就自動追溯判定。滿級出擊不受爬坡影響，一律全開。
- 首次擊破摩洛克的當下會記錄耗時並標記通關，但**不會中斷對局**——這是無限刷分街機，在此結束會讓玩家損失分數。該紀錄之後永久有效，即使該局最終戰敗，上傳成績仍會帶上「最快通關」時間。
- Boss會在進場時開始射擊，並依序輪換破城機甲「巴別」、空中母艦「利維坦」、熔核巨像「摩洛克」；三者擁有不同體型、移動、彈速、射擊原點與專屬攻擊。
- 利維坦的「變軌獵殺」不再使用固定左／中／右模板：射線由母艦當下位置發出，依指揮官位置動態鎖定，階段1／2為2道、階段3為3道，先顯示完整預警軌跡再依指揮官中心判定。
- 第二隻Boss起依序加入突擊增援、護盾核心、高壓彈幕與核心過載，後期混合兩種戰型；機體輪換與戰型詞綴彼此獨立。
- Boss全屏攻擊改為整隊只結算一次的全域殲滅：損失30%當前兵力、無視裝甲與格擋，指揮官技能可中斷，真正無敵可防護。
- 全域殲滅由首領階段遞增為1／2／3次，預警從2.4秒縮短至1.6秒；第6隻Boss起，戰鬥45秒後每12秒追加一次狂暴攻擊。
- 配樂重製為十六小節「建立／主題／對比／回歸」曲式，研究經典街機射擊遊戲的旋律清晰度與關卡敘事，但所有旋律、和聲與編曲均為原創，不挪用既有遊戲音樂。
- 港區是沉著軍步、峽谷是開闊追擊、首都是半拍攻堅、鑄造廠是低重心機械律動、雪原使用大量留白、天際線才真正全速推進；巴別、利維坦與摩洛克各自採巨構儀式、盤旋追獵與熔爐決戰語彙。
- 每首曲子以同一組五音識別動機形成共同作品身份，但使用不同調式、速度、節拍重心與句尾。非留白小節至少有一個穩定和弦落點，六戰區平均主旋律密度不超過每小節四音。
- Pad、分解和弦與機械脈衝不再同時常駐；主旋律不以高八度複製堆疊。Boss轉階只做克制的力度與句尾變化，不再強制加速。全域殲滅蓄力時抽離主鼓與旋律，只保留低頻警戒層。
- 混音保留實際動態，不再模仿嘈雜街機廳的音量競賽；手機頻段優先保護旋律，槍聲另走低增益匯流排。
- 完整設計原則與各場景敘事記錄於 `MUSIC-DIRECTION.md`。
- 暫停、安全撤離、死亡結果與強制撤退確認會清空已排程音源並休眠；網頁切到背景時立即靜音，回到遊戲後需再次互動才恢復。
- 可在 `src/audio-assets.js` 接入完整混音或鼓、低音、旋律、張力同步分軌；正式建置會內嵌素材，遠端網址僅建議用於臨時預覽。
- 我方隊伍顯示即時士兵數，指揮官固定在中央後排；Boss只保留一條不遮擋武器資訊的上方血條。
- 成就分為每日／戰績、指揮官系列，以及九項研究各九級（共 81 項）；每項研究勳章使用3×3排列。
- 成就圖示欄會依 `MAX`、`×1.2`、`◇10` 等寬圖示自動調整，不會再覆蓋標題或把說明擠出卡片。
- 六種武器各有符合自身特性的實戰專精；單純取得高能雷射不再送成就，全部完成後解鎖「六械宗師」。
- 永久戰績包含20／50／100／200／300五階連殺、10,000至100,000,000的十二階積分里程碑，以及完美二選一、零支援擊破、無傷Boss、殘兵勝利、六武器與六戰區系列。
- 積分里程碑採漸進顯示：只露出已達成的階數，加上緊接的下一階，更後面完全隱藏。最高的5,000萬與1億兩階是隱藏天花板，要一路打上去才會現身；區段標題也不顯示總階數，避免把天花板洩漏出去。
- 線上排行榜由 Supabase 提供，分為總分、最快通關、Boss擊殺三個榜單，各自獨立取每位玩家的最佳成績——總分最高的那局不一定也是速通最快的那局。暱稱最多16字，另以存在本機、不顯示的匿名識別碼判定「是不是同一個人」，解決撞名互相覆蓋的問題。上傳前若這局沒有突破自己任一項紀錄會跳確認，但仍可選擇上傳；上傳成功後直接顯示排名，而不只是「上傳成功」。
- 排行榜沒有防作弊機制，成績由玩家端自行回報。這是刻意的取捨，換取後端維持在免費層、不需自架伺服器；若之後真的被濫用，最快的處理是去 Supabase 後台收緊 insert policy，不需重新部署遊戲。
- 「十全指揮」只代表招募全部10位；「十機實戰」另行記錄每位指揮官是否曾擊破Boss。擁有兩位以上指揮官後，每日任務池會加入輪值出擊。
- 十位指揮官各有一項對應自身玩法的專屬成就，另有十項首次施放技能的實戰認證；完成整條系列分別解鎖「全機精通」與「十機戰術」。每日任務池在十機全部招募後會加入「十機輪值」，只計算當日使用過的不同指揮官。
- 研究81/81後開放後期軍備合約：標準、高壓、鐵壁與滅絕四種威脅協定依最高戰績解鎖。協定提高敵軍威脅與顯示戰績，但不放大軍備點結算。
- 可在選定指揮官後加購一次性「滿級出擊」：本循環所有武器暫定LV.9、裝甲補到MAX，兵力與技能照常；擊破下一隻Boss後失效，不改寫永久研究或真實武器等級。費用依指揮官價格與當前Boss輪次提高，也可在10秒安全窗口直接替下一循環預約；返回戰場前可取消並全額退款，進入下一戰區後鎖定且強制撤退也不能退款。
- 移除會誤導碰撞範圍的隊形裝甲外圈與重複讀值，裝甲只保留畫面底部狀態。
- 升級門採受控隨機並提供火力保底；技能擊殺不再自我回充或累積自然狂熱，施放後需10秒整備。
- 滿級火力會啟動敵軍反制協議，後續加入爆甲狙擊、側翼砲塔與戰區砲擊；空投獎勵同步降頻。
- 續航改為稀缺資源：動員研究每級 +1、常態增援 +2、危急增援 +3、裝甲修復最多 +2。
- 戰區砲擊若未躲開，會無視裝甲與格擋並直接損失當前兵力的一半；有效無敵仍可防護。
- 砲擊會忽略普通受擊保護；只有技能、醫療支援、重生與檢查點進場的真正無敵可防護。
- 六種武器使用不同的曳光長度、粗細、光芯與命中特效；Boss會依剩餘生命顯示裝甲裂痕、核心過載與轉階演出。
- 六個戰區各有獨立地標、色調與氣氛粒子；三種Boss使用不同輪廓、核心與受損表現。指揮官技能保留短促戰術切入，不延長操作鎖定時間。
- 衝擊手感恢復 V8.5.1 的完整逐幀震幅，但把接近戰線、核心背景、接敵線與所有戰鬥物件綁在同一個鏡頭一起位移；畫面四周預繪 16px 餘量，保留強烈打擊感而不在接敵線上下撕裂或露出黑邊。DOM HUD、支援鈕、技能鈕與下方操控區維持固定。
- 全螢幕機動區只保留一條實線作為戰場分界；原本容易被誤認為第二條界線的裝飾虛線已移除，中央僅保留左右拖曳圖示與說明。
- 密集彈幕採樣式批次繪製、子彈物件回收與粒子上限；自動畫質會在持續掉幀時逐級減少光暈與氣氛粒子，穩定後自動恢復。

## 存檔

V8 存檔結構沿用瀏覽器 `localStorage` 的 `firestorm-v6-profile` 鍵名。首次啟動會嘗試讀取 V5 的軍備點、指揮官、研究、成就與舊檢查點；既有V6存檔會自動補齊後期合約、積分成就、技能紀錄、全螢幕偏好，以及排行榜相關的暱稱、匿名識別碼、個人最佳成績與場地機制畢業標記，舊資料不會被主動刪除。

完整規則與平衡數值請見 [`GAME-MECHANICS.md`](GAME-MECHANICS.md)；專案現況與未完成項目請見 [`PROJECT-STATUS.md`](PROJECT-STATUS.md)。
